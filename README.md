# SentinelRL: Budgeted Adaptive Cyber Defence

SentinelRL is an independently written, CPU-runnable reinforcement-learning mini-project. It studies whether a Deep Q-Network (DQN) can make useful inspection, patching, isolation and decoy-placement decisions in a small *synthetic* enterprise network when the defender has noisy alerts and only six response actions per episode.

> **Scope and safety:** this is an abstract teaching simulator. It does not connect to a network, send packets, scan devices, run exploits, or contain executable attack code. All compromise events are generated by simple stochastic transitions. Results are simulation results only, not evidence of real-world security effectiveness.

## Requirements

- Python 3.10 or newer (tested in this environment with Python 3.13)
- CPU is sufficient; no GPU, external API, private data or live network required
- Dependencies: NumPy, pandas, Matplotlib, PyTorch and pytest

## Install and test

From this directory:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux:       source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
# For the exact tested versions, use: python -m pip install -r requirements-tested.txt
python -m pytest -q
```

The committed test run completed with **6 passing tests**. Tests cover deterministic resets/transitions, observation and action dimensions, finite rewards, always-available WAIT action, response-budget bounds, training updates and checkpoint round-tripping.

## Reproduce training and evaluation

Run the full pipeline (280 training episodes for each of three seeds; 30 held-out episodes per baseline; 20 episodes per attack-intensity condition):

```bash
python run_all.py --episodes 280 --eval-episodes 30
```

It writes checkpoints under `models/` and experimental outputs under `results/`. Full execution can take several minutes on CPU.

To train only:

```bash
python train.py
```

To evaluate already-trained checkpoints and regenerate standard comparison plots:

```bash
python evaluate.py
```

`evaluate.py` prompts for the number of held-out episodes per baseline. To change the attack intensity in the sensitivity run, edit the documented `attack_rates` tuple in `src/experiment.py`; do not alter test conditions only to make a particular agent look better.

## Main outputs

- `results/training_episodes.csv`: one row per training episode and seed
- `results/evaluation_episodes.csv`: one row per held-out DQN/baseline episode
- `results/summary.csv` and `summary.json`: mean and standard deviation by policy
- `results/sensitivity_episodes.csv` and `sensitivity_summary.csv`: held-out attack-rate sensitivity
- `results/EXPERIMENT_METADATA.md`: package versions, seeds, run counts and verification record
- `results/training_curve.png`, `critical_compromises.png`, `uncontained_at_end.png`, `detection_delay.png`, `false_isolations.png`, `sensitivity_critical_compromises.png`

The report's numbers are drawn from the saved output CSVs. **DQN does not beat the strongest hand-coded policies in every metric.** That is reported as a genuine finding, not concealed: DQN improves over the random and patch-only baselines in critical compromise counts, but Alert Responder and Threshold Defense remain stronger on overall returns and containment in this compact simulator.

## How actions work

The discrete action ID is:

- `0`: wait
- `1..6`: inspect host 0..5
- `7..12`: patch host 0..5
- `13..18`: isolate host 0..5
- `19..24`: deploy a decoy on host 0..5

The environment exposes a boolean action mask. The DQN applies it both during action selection and in next-state Q-value targets. The agent never interacts with real systems.

## Model and reproducibility

- Training seeds: `17`, `29`, `43`
- Standard held-out evaluation episode seeds begin at `300000`
- Attack-rate sensitivity seeds begin at `400000`
- Checkpoints store the model weights, model configuration, training step counts and metadata
- Evaluation is deterministic conditional on model checkpoint and environment seed, except for randomized baseline policies whose own seed is fixed per evaluation episode
